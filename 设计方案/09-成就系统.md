## 二·附、成就条件计数规则

以下规则适用于所有成就的条件判定，避免歧义：

| 条件类型 | 计数基准 | 说明 |
|---------|---------|------|
| 击杀怪物 | 以击杀动画完成（怪物死亡）为准，最后一击者计数 | 多人场景下归属最后一击 |
| 击杀Boss | 以Boss死亡且获得掉落为准，需在Boss房间内 | 离线不计 |
| 探索区域 | 进入区域并触发"发现"提示即算探索完成 | 无需100%采集 |
| 收集材料 | 以曾经拥有过为准（图鉴解锁），不要求当前持有 | 卖出/消耗不影响计数 |
| 收集装备 | 以曾经拥有过为准（图鉴解锁），不要求当前穿戴 | 分解/卖出不影响计数 |
| 打造/生产 | 以产出物进入背包为准 | 打造失败不计 |
| 强化 | 以强化成功为准，失败不计数也不重置累计 | 连续成功成就中断后从零计 |
| 修炼时长 | 以在线挂机+离线收益的总时间累计 | 暂停不计 |
| 通关副本 | 以击杀最终Boss且结算完成为准 | 中途退出不计 |
| 连续登录 | 以每日首次登录为准，跨自然日零点重置 | 断签从零计 |
| 功法击杀 | 使用主动功法技能造成最后一击 | 普攻击杀不计 |
| 特殊天气 | 以采集时天气状态为准，需在天气生效期间完成采集 | 天气结束后采集不计 |
| 洗练/重铸 | 以点击确认并消耗材料为准，无论结果好坏均计数 | — |
| 传承 | 以传承操作完成为准 | — |
