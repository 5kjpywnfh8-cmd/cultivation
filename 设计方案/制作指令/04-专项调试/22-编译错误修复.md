# 编译错误修复指令

代码编译/类型检查报错时使用。

---

修复当前编译错误。

【调试步骤】
1. 执行 npm run build 或 vue-tsc --noEmit 获取完整错误列表
2. 按文件分组整理错误
3. 从第一个错误开始修复（后续错误可能是连锁反应）
4. 每修复一个文件，重新检查该文件是否还有错误
5. 全部修复后，执行完整编译验证无报错

【常见错误类型】
- 类型不匹配：检查接口定义和实际数据结构
- 未定义的变量/属性：检查拼写、导入、大小写
- 缺少依赖：检查 import 路径
- 泛型错误：检查类型参数

【输出要求】
- 错误列表（文件、行号、错误信息）
- 每个错误的修复方案
- 修复后编译验证结果

开始。
