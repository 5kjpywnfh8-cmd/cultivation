# 制作指令总览

本目录包含《星渊仙途》Phase 1 MVP 开发的全部指令模板。

## 使用方式

1. 输入 `/automode` 开启自动批准模式
2. 复制对应指令粘贴执行
3. 按 `Esc` 可暂停，输入 `继续` 恢复
4. 会话中断后开新会话，粘贴断点续接指令

## 常用流程

| 场景 | 指令 |
|------|------|
| 首次开发 | `05-工程管理/15-环境搭建.md` → `01-开发执行/01-Phase1完整执行.md` |
| 中断恢复 | `01-开发执行/03-断点续接.md` |
| 遇到报错 | `05-工程管理/16-错误调试.md` 或 `04-专项调试/22-编译错误修复.md` |
| 完成一个模块 | `02-审查修复/05-模块审查.md` |
| 全部完成 | `02-审查修复/06-整体审查.md` → `03-验证优化/08-功能验证.md` → `03-验证优化/14-浏览器测试.md` |

## 注意事项

- 数值冲突时以 `补充-数值公式统一.md` 为准
- 存档结构以 `补充-存档数据结构.md` 为准
- UI 以 `补充-UI布局设计.md` 为准
- 参考 `审查报告/总结报告.md` 避免重复引入已知问题
