# 制作指令总览

本目录包含《星渊仙途》全部开发指令模板。

## 使用方式

1. 输入 `/automode` 开启自动批准模式
2. 复制对应指令粘贴执行
3. 按 `Esc` 可暂停，输入 `继续` 恢复
4. 会话中断后开新会话，粘贴断点续接指令

## 常用流程

| 场景 | 指令 |
|------|------|
| Phase 1 开发 | `A-开发执行/A01-Phase1完整执行.md` |
| Phase 2 完整开发 | `A-开发执行/A02-Phase2完整执行.md` |
| Phase 2 单模块 | 见下方模块速查 |
| 中断恢复 | `A-开发执行/A03-断点续接.md` |
| 遇到报错 | `E-工程管理/E02-错误调试.md` 或 `D-专项调试/D01-编译错误修复.md` |
| 完成一个模块 | `B-审查修复/B02-模块审查.md` |
| 全部完成 | `B-审查修复/B03-整体审查.md` → `C-验证优化/C01-功能验证.md` |

## 命名规则

- **A/B/C/D/E** — 类别前缀，便于排序和筛选
- **01-99** — 类别内序号，便于补充新指令
- **中文描述** — 简明说明用途

## 补充新指令

在对应类别目录下新建文件，按序号递增命名即可：
- 新增开发指令 → `A-开发执行/A10-xxx.md`
- 新增审查指令 → `B-审查修复/B05-xxx.md`
- 新增调试指令 → `D-专项调试/D06-xxx.md`

## 注意事项

- 数值冲突时以 `补充-数值公式统一.md` 为准
- 存档结构以 `补充-存档数据结构.md` 为准
- UI 以 `补充-UI布局设计.md` 为准
- 参考 `审查报告/总结报告.md` 避免重复引入已知问题
- Phase 2 不能破坏 Phase 1 已有功能
