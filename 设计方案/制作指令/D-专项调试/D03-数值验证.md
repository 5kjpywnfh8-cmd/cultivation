# 数值验证指令

验证游戏数值与设计文档一致。

---

对 Phase 1 的数值做全面验证。

【验证范围】
1. 境界属性表（60级）：attack、defense、hp、starYuanCost 与 01-游戏核心设计.md 一致
2. 装备属性：品质系数、部位系数、强化系数 1.25^n 与 04-装备系统.md 一致
3. 伤害公式：减伤率、暴击、穿透计算与 06-战斗与Boss系统.md 一致
4. 星元需求：每级星元消耗与设计文档一致
5. 商店价格：商品价格与 05-商店系统.md 一致
6. 掉落概率：怪物掉落表与 06-战斗与Boss系统.md 一致
7. 强化成功率：max(5%, 100% - level × 0.5%) 与设计文档一致
8. 离线收益：采集/战斗离线系数与设计文档一致
9. 货币产出：各境界星币/灵石产出速率与设计文档一致

【验证方法】
- 读取 config.js / JSON 配置文件中的数值
- 逐个与设计文档中的数值表核对
- 如有差异，以 补充-数值公式统一.md 为准

【输出要求】
- 每项数值的验证结果（一致/不一致）
- 不一致项的具体差异和修正方案
- 修正后重新验证

开始。
