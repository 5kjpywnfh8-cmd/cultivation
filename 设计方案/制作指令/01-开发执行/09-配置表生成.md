# 配置表生成指令

批量生成 Phase 1 所需的 JSON 配置文件。

---

按设计文档生成 Phase 1 MVP 所需的全部配置表。

【配置清单】
1. src/config/realm-stats.json — 60级境界属性（参考 01-游戏核心设计.md 3.5节）
2. src/config/equipment-templates.json — 装备模板（参考 04-装备系统.md）
3. src/config/planet-config.json — 星球资源配置（参考 02-星球与资源系统.md）
4. src/config/monster-templates.json — 怪物/Boss模板（参考 06-战斗与Boss系统.md）
5. src/config/shop-config.json — 商店商品（参考 05-商店系统.md）
6. src/config/enhance-config.json — 强化配置（参考 04-装备系统.md 强化部分）
7. src/config/skill-templates.json — 功法配置（参考 07-技能系统.md）

【生成规则】
- 严格按设计文档中的数值表生成，不自行调整
- 数值冲突时以 补充-数值公式统一.md 为准
- 每个配置文件必须包含 version 字段
- JSON 格式规范，有注释说明（JSON5 或 _comment 字段）

【审查规则】
- 生成后逐个与设计文档核对数值
- 循环审查到所有配置与设计文档完全一致

开始。
