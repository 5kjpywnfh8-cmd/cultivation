# 浏览器测试指令

在浏览器中手动测试游戏功能。

---

启动项目并在浏览器中测试。

【测试步骤】
1. 启动开发服务器（npm run dev）
2. 在浏览器中打开页面
3. 按以下清单逐项测试

【测试清单】
- [ ] 页面正常加载，无白屏
- [ ] 导航栏可切换各页面
- [ ] 境界修炼：星元累积、突破成功
- [ ] 星球探索：切换星球、资源显示正确
- [ ] 资源采集：手动采集、自动采集
- [ ] 装备打造：消耗材料、产出装备
- [ ] 装备穿戴/卸下：属性变化正确
- [ ] 装备强化：成功/失败、属性变化
- [ ] 自动战斗：伤害计算、怪物死亡、掉落
- [ ] Boss战：手动操作、技能释放
- [ ] 商店：购买商品、货币扣除
- [ ] 存档/读档：关闭重开数据不丢失
- [ ] 离线收益：关闭后重开有收益弹窗
- [ ] 响应式布局：拖拽窗口测试断点
- [ ] 控制台无报错

【输出要求】
- 每项测试的通过/失败状态
- 失败项的截图描述和修复建议

开始。
