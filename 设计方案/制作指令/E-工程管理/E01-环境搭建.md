# 环境搭建指令

初始化项目环境和依赖。

---

初始化 Phase 1 MVP 项目环境。

【执行步骤】
1. 检查 Node.js 版本（要求 >= 18）
2. 使用 Vite 创建 Vue3 + TypeScript 项目
3. 安装依赖（vue、vite、typescript、vue-tsc）
4. 配置 tsconfig.json（strict 模式）
5. 配置 vite.config.ts
6. 创建目录结构：src/core、src/systems、src/ui、src/config、src/utils
7. 创建入口文件 main.ts、App.vue
8. 验证 npm run dev 可正常启动

【输出要求】
- 安装的依赖列表和版本
- 创建的目录结构
- 启动验证结果

开始。
