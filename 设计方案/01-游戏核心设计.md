# 游戏核心设计

## 一、世界观

星际修仙文明崩溃三百年后，修士散落各星球，靠吸收「星元」修炼。主角是一名低阶修士，驾驶星舟穿梭各星球，收集资源、击败异兽、种植灵植，最终证道飞升。

## 二、核心循环

```
探索星球 → 采集/战斗/种田 → 获得资源与货币
    ↓                              ↓
  解锁新星球 ← 修炼提升 ← 商店兑换 ← 装备强化
```

## 四、属性体系

| 属性 | 作用 | 来源 |
|------|------|------|
| 攻击 | 基础伤害 | 装备+境界+功法 |
| 防御 | 减少受到伤害 | 装备+境界+功法 |
| 生命 | 承受伤害上限 | 装备+境界+功法 |
| 暴击率 | 暴击概率 | 装备词条+功法 |
| 暴击伤害 | 暴击倍率（默认150%） | 装备词条+功法 |
| 穿透 | 无视目标防御比例 | 装备词条+功法 |
| 闪避率 | 闪避攻击概率 | 装备词条+功法 |
| 生命回复 | 每秒回复生命 | 装备词条+丹药 |

**全局属性约束**：

| 属性 | 硬上限 | 软上限 | 说明 |
|------|--------|--------|------|
| 暴击率 | 80% | 30% | 超过30%部分效果减半，硬上限80% |
| 暴击伤害 | 300% | 100% | 超过100%部分效果减半，硬上限300% |
| 穿透 | 75% | 30% | 超过30%部分效果减半，硬上限75% |
| 闪避率 | 50% | 25% | 超过25%部分效果减半，硬上限50% |
| 攻击/防御/生命加成 | 200% | 50% | 超过50%部分效果减半，硬上限200% |

> 软上限：超出部分效果减半。硬上限：任何手段不可超越的绝对上限。此约束防止属性堆叠导致无敌或秒杀，与"11-数值平衡总表.md"7.2节软上限体系一致。

## 五、伤害公式

**核心伤害公式**：

```
实际伤害 = 攻击 × 技能倍率 × (1 - 目标减伤率) × 暴击系数

减伤率 = 防御 ÷ (防御 + 1000 + 攻击方等级 × 50)
暴击系数 = 暴击时为 (1.5 + 暴击伤害加成)，否则为1
```

> 减伤率公式在高等级时可趋近100%（如97.4%），但始终留有伤害空间。

**穿透计算**：

```
有效防御 = 目标防御 × (1 - 穿透比例)
实际减伤率 = 有效防御 ÷ (有效防御 + 1000 + 攻击方等级 × 50)
```

> 穿透在减伤率计算前生效，直接降低目标有效防御值。穿透受全局约束（软上限30%，硬上限75%）。

**最低伤害保底规则**：

```
最终伤害 = max(攻击 × 1%, 计算伤害)
```

> 此规则防止因减伤率趋近100%导致伤害归零，确保战斗始终有推进。
