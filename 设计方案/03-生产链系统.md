# 生产链系统

## 一、生产链总览

```
玄铁星→铁矿 ──┐
灵植星→灵液 ──┼→ 生产线 → 修炼丹药/装备材料
幽冥星→魂石 ──┘
```

不同星球提供不同原料，需要跨星球物流串联，才能生产高级产物。

## 二、三条主线

### 线路A：装备材料线

```
铁矿（玄铁星）+ 铜矿（玄铁星）
    ↓ 熔炼炉
合金锭（第一章即可生产）
    ↓ + 木晶（灵植星，第三章解锁）
精炼合金锭
    ↓ 精炼台 + 天晶（天晶星，元婴期解锁）
精炼合金
    ↓ 锻造台
装备核心材料（用于打造装备）

分支：合金锭 + 魂石（幽冥星）→ 幽冥合金（金丹期可用）
```

### 线路B：修炼丹药线

```
灵液（灵植星）+ 生命露水（灵植星）
    ↓ 蒸馏器
浓缩灵液
    ├─→ 炼丹炉 → 聚灵散（星元获取+20%，20分钟）
    ├─→ 炼丹炉 + 魂石（幽冥星）→ 凝魂丹（星元获取+30%，30分钟）
    │                              ↓ 炼丹炉 + 道韵碎片（混沌星）
    │                              道韵丹（境界突破辅助材料）
    └─→ 炼丹炉 + 雷髓（天晶星）→ 雷髓丹（战斗攻击+15%，30分钟）
```

### 线路C：强化材料线

```
星尘（玄铁星）+ 暗苔（幽冥星）
    ↓ 萃取机
星尘精华
    ↓ 萃取机（星尘精华×2 + 暗苔×1）→ 产出2个
强化石（低级）（筑基期可生产）
    ↓ 熔炼炉（星尘精华×3 + 暗苔×3）→ 产出1个
强化石（中级）（金丹期可生产）
    ↓ 精炼台 + 混沌石（混沌星）
高级强化石
    ↓ 精炼台 + 电弧石（天晶星）+ 幽冥火（幽冥星）
传说级强化石（二周目+16~+25强化）
    ↓ 精炼台 + 道韵碎片（混沌星）+ 混沌石（混沌星）
神话级强化石（二周目+26~+30强化）
```

## 三、生产设备

| 设备 | 功能 | 解锁条件 | 升级收益 |
|------|------|---------|---------|
| 熔炼炉 | 矿物冶炼 | 初始 | 产量+20%/级，最多5级 |
| 蒸馏器 | 灵液提纯 | 筑基期 | 产量+20%/级 |
| 萃取机 | 星尘/暗苔萃取 | 筑基期 | 产量+15%/级 |
| 炼丹炉 | 丹药炼制 | 金丹期 | 成功率+10%/级，品质概率提升 |
| 精炼台 | 材料精炼 | 金丹期 | 产量+15%/级 |
| 锻造台 | 装备打造 | 初始 | 品质概率提升/级 |
| 空间折叠器 | 所有设备加速 | 化神期 | 全设备速度+10%/级 |

### 生产速度完整公式

```
单次生产时间 = 基础时间 ÷ (1 + 设备等级 × 设备加速系数) ÷ (1 + 空间折叠器等级 × 0.1) ÷ (1 + 科技树生产速度加成) ÷ 批量生产蓝图倍率 ÷ 星际传送门倍率
```

**各设备加速系数**：

| 设备 | 加速系数 | 说明 |
|------|---------|------|
| 熔炼炉 | 0.2 | 每级+20%速度 |
| 蒸馏器 | 0.2 | 每级+20%速度 |
| 萃取机 | 0.15 | 每级+15%速度 |
| 精炼台 | 0.15 | 每级+15%速度 |
| 炼丹炉 | 不适用 | 炼丹炉升级提升成功率和品质，不影响速度 |
| 锻造台 | 不适用 | 锻造台升级提升品质概率，不影响速度 |

> 注：炼丹炉和锻造台不享受设备速度加成，它们的升级收益体现在成功率/品质提升上。炼丹炉生产时间仅受空间折叠器、批量蓝图和传送门影响。

**加速来源汇总**：

| 加速来源 | 倍率 | 解锁条件 |
|---------|------|---------|
| 设备升级（熔炼炉/蒸馏器每级+20%，萃取机/精炼台每级+15%，最多5级） | ×2.0 / ×1.75 | 消耗材料升级设备 |
| 空间折叠器（每级+10%，最多5级） | ×1.5 | 化神期解锁 |
| 科技树·基础工艺（生产速度+20%） | ×1.2 | 科技树T1，筑基期可研究 |
| 科技树·超频生产（生产速度×3） | ×3.0 | 科技树T6，化神期可研究 |
| 批量生产蓝图 | ×2.0 | 元婴期科技树解锁（同时间产出翻倍，公式中作为时间除数） |
| 星际传送门蓝图 | ×2.0 | 元婴期科技树解锁 |
| **理论总加速（熔炼炉/蒸馏器）** | **×43.2** | 全部解锁后 |
| **理论总加速（萃取机/精炼台）** | **×37.8** | 全部解锁后 |

## 五、生产效率优化路径

```
阶段1（练气-筑基）：手动采集 + 基础设备
  → 产出慢，但够用（×1.0 加速）

阶段2（金丹期）：多星球建立采集点 + 自动运输 + 设备升级3级
  → 产出提升2-3倍（×1.6~2.4 加速）

阶段3（元婴期）：星际传送门 + 批量蓝图 + 设备升级满
  → 产出提升5-8倍（×8.0 加速）

阶段4（化神期）：空间折叠器 + 全自动化
  → 产出提升10-15倍（×12.0 加速）
```
