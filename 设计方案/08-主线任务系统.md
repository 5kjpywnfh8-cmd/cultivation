# 主线任务系统

## 一、设计理念

```
主线任务 = 引导 + 解锁 + 奖励 + 剧情

核心原则：
  1. 每个任务教一个玩法或解锁一个系统
  2. 奖励是玩家当前阶段最需要的东西
  3. 任务之间有逻辑递进，不是随机堆砌
  4. 单机游戏可以肝但不能卡，卡点给明确目标
```

## 四、剧情梗概

### 序章
> 星历3024年，修仙文明崩溃三百年后，你是一名低阶修士，驾驶星舟在星际间流浪。一次意外，星舟坠毁在玄铁星……

### 第零章
> 你在起源星醒来，记忆模糊，只记得自己是一名修士。周围是一片荒芜的矿野，星舟破败不堪。你必须采集矿石、打造武器、建造研究台，修复星舟，才能离开这颗星球，前往更广阔的星域……

### 第一章
> 你在废墟中醒来，发现星舟损毁严重。必须收集资源修复星舟，同时恢复自己的修为。玄铁星的矿脉深处，似乎隐藏着什么秘密……

### 第二章
> 星舟修复后，你发现玄铁星深处有一座远古遗迹。遗迹中的记录提到，修仙文明崩溃的原因与一种叫"混沌之力"的能量有关……

### 第三章
> 根据遗迹线索，你来到灵植星。这里的灵植异常茂盛，似乎受到了混沌之力的影响。你需要收集灵植，炼制丹药，提升实力……

### 第四章
> 幽冥星的亡灵越来越多，你前往调查。发现亡灵的产生与混沌之力的泄漏有关。你必须阻止泄漏，同时收集魂石突破金丹……

### 第五章至第十章
> 随着探索深入，你发现混沌之力的源头在混沌星。你需要依次探索天晶星、混沌星，收集对抗混沌之力的力量，最终渡劫飞升，成为修仙文明崩溃后第一位飞升的修士。
