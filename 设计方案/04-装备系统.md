## 四、强化系统

### 强化等级上限

- 一周目：+15（硬上限）
- 二周目~五周目：+30（硬上限）
- 无尽模式：无硬上限（+50以上采用衰减公式，详见补充-数值公式统一.md 2.3节）

```
强化系数 = 1.25 ^ 强化等级
```

| +12 | 14.55 | 1355% |
| +13 | 18.19 | 1719% |
| +14 | 22.74 | 2174% |

### 强化消耗

```
强化石数量 = 境界等级 × (1 + 强化等级 × 0.1)
星币消耗 = 100 × 境界等级² × (1.2 ^ 强化等级)
```

| 强化等级 | 强化石（金丹30级基准） | 星币（金丹30级基准） |
|---------|----------------------|---------------------|
| +3 | 39颗 | 16万 |
| +6 | 48颗 | 27万 |
| +9 | 57颗 | 46万 |
| +12 | 66颗 | 80万 |
| +15 | 75颗 | 139万 |

### 强化成功率

```
成功率 = max(5%, 100% - 强化等级 × 0.5%)
```

| 强化段 | 成功率范围 | 说明 |
|--------|-----------|------|
| +1 ~ +50 | 100% ~ 75% | 基本必成 |
| +51 ~ +100 | 75% ~ 50% | 有失败风险 |
| +101 ~ +150 | 50% ~ 25% | 需要多次尝试 |
| +151 ~ +190 | 25% ~ 5% | 高风险区 |
| +190+ | 5%（保底） | 极限挑战 |

**失败惩罚规则**：

| 强化段 | 失败惩罚 | 保护符效果 |
|--------|---------|-----------|
| +0 ~ +100（含100） | 无变化 | — |
| +101 ~ +200（含200） | 降1级 | 不降级 |
| +201 及以上 | 降2级 | 只降1级 |

> 一周目强化上限为+15，在该范围内成功率始终高于92.5%，失败无惩罚。二周目上限+30，+0~+100失败无变化。+101以上失败会降级，保护符为必需品（需电弧石+幽冥火制作，详见03-生产链系统.md 4.3节）。无尽模式无硬上限，+50以上采用衰减公式（详见补充-数值公式统一.md 2.3节）。

## 五、词条系统

### 5.1 词条槽

- 每件装备有5个词条槽
- 每+10强化等级额外获得1个词条槽
- 槽1-3：主词条（正面效果）
- 槽4：副词条（随机正面或负面，60%/40%概率）


### 5.5 防无敌机制

**软/硬上限**：以《01-游戏核心设计.md》四、属性体系中「全局属性约束」为准：

| 属性 | 软上限 | 硬上限 | 说明 |
|------|--------|--------|------|
| 暴击率 | 30% | 80% | 超过30%部分效果减半，硬上限80% |
| 暴击伤害 | 100% | 300% | 超过100%部分效果减半，硬上限300% |
| 穿透 | 30% | 75% | 超过30%部分效果减半，硬上限75% |
| 闪避率 | 25% | 50% | 超过25%部分效果减半，硬上限50% |
| 攻击/防御/生命加成 | 50% | 200% | 超过50%部分效果减半，硬上限200% |

> 软上限：超出部分效果减半。硬上限：任何手段不可超越的绝对上限。此约束防止属性堆叠导致无敌或秒杀。

### 5.6 词条随机化规则

词条生成采用**权重池抽取 + 数值区间随机**机制：

**抽取流程**：
1. 根据词条槽类型（主/副/特殊）确定候选池
2. 按权重随机抽取词条类型（互斥组内同类型权重共享）
3. 在该词条的数值区间内随机生成具体数值

**数值随机分布**：
```
词条数值 = 最小值 + (最大值 - 最小值) × 随机因子
随机因子：偏向中间值的正态分布（均值0.5，标准差0.15），截断至[0, 1]
```

**品质影响词条数值**：
| 品质 | 数值区间偏移 |
|------|-------------|
| 普通（白） | 区间下限 × 60% ~ 上限 × 80% |
| 精良（绿） | 区间下限 × 70% ~ 上限 × 90% |
| 稀有（蓝） | 区间下限 × 80% ~ 上限 × 100% |
| 史诗（紫） | 区间下限 × 90% ~ 上限 × 110% |
| 传说（橙） | 区间下限 × 100% ~ 上限 × 120% |
| 神话（红） | 区间下限 × 110% ~ 上限 × 130% |
| 太古（金） | 区间下限 × 120% ~ 上限 × 140% |

**重铸规则**：
- 消耗重铸石×1 + 星币，重新随机指定词条槽的类型和数值
- 重铸可锁定1-2个词条不被重铸（锁定费用翻倍）
- 重铸不降低词条槽数量

- 同一套装的6件装备可混合品质（如3件稀有+3件史诗），套装效果按最低品质件计算加成

## 七、打造流程

```
收集材料 + 图纸 → 锻造台打造 → 获得基础装备
                              ↓
                      消耗强化石强化
                              ↓
                   每+10获得词条槽 → 重铸词条
```

**打造消耗**：
```
材料数量 = 5 + 品质等级 × 3
星币 = 500 × 境界等级²
```

**品质概率提升方式**：使用高级图纸、添加催化剂材料、锻造台升级。

分解装备返还部分材料，用于打造新装备：

```
返还材料数量 = 原始打造材料 × 30%（向上取整）
```

|------|-------------|
