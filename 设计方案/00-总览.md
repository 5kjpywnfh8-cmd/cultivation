# 《星渊仙途》游戏设计方案总览

## 一、项目概述

**游戏名称**：星渊仙途
**游戏类型**：科幻修仙放置游戏
**参考游戏**：梅尔沃放置、觅长生、戴森球计划
**平台**：PC/Web
**核心玩法**：探索星球、采集资源、生产制造、装备打造、Boss战斗、放置修炼

## 二、世界观

星际修仙文明崩溃后，修士散落各星球，靠吸收「星元」修炼。主角是一名低阶修士，驾驶星舟穿梭各星球，收集资源、击败异兽、种植灵植，最终证道飞升。

## 三、核心循环

```
探索星球 → 采集/战斗/种田 → 获得资源与货币
    ↓                              ↓
  解锁新星球 ← 修炼提升 ← 商店兑换 ← 装备强化
```
