# 《星渊仙途》制作计划总览

## 一、项目概况

| 项目 | 信息 |
|------|------|
| 游戏名称 | 星渊仙途 |
| 游戏类型 | 科幻修仙放置游戏 |
| 技术栈 | HTML + CSS + 原生JS（零配置） |
| 目标代码量 | ~10,000行 |
| 预计工期 | 2-4周（AI辅助） |
| 开发方式 | Vibe Coding + AI辅助 |

## 二、开发阶段

| 阶段 | 内容 | 代码量 | 工期 | 优先级 |
|------|------|--------|------|--------|
| Phase 1 | 核心循环（MVP） | ~2,500行 | 3-5天 | ⭐⭐⭐ |
| Phase 2 | 内容扩展 | ~2,500行 | 5-7天 | ⭐⭐ |
| Phase 3 | 深度玩法 | ~2,500行 | 5-7天 | ⭐ |
| Phase 4 | 终局内容 | ~2,500行 | 5-7天 | ⭐ |

## 三、核心循环（MVP）

```
修炼境界 → 探索星球 → 采集资源 → 打造装备 → 战斗Boss → 解锁新星球
    ↑                                                    ↓
    └────────────────── 商店兑换 ←──────────────────────┘
```

│   ├── combat.js           ← 战斗系统

## 五、技术选型

| 层级 | 选择 | 理由 |
|------|------|------|
| 渲染 | DOM + CSS Grid | 零配置，适合UI密集型游戏 |
| 状态管理 | 全局对象 + 事件 | 简单直接，无需框架 |
| 存储 | localStorage | 零依赖，浏览器原生 |
| 构建 | 无 | 双击index.html直接运行 |
| 部署 | GitHub Pages | 免费，零配置 |
