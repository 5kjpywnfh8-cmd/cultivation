# 战斗与Boss系统

## 一、战斗系统基础

### 1.1 战斗模式

```
普通区域：自动战斗（放置挂机）
Boss战：手动操作（选择技能释放时机）
副本：限时挑战（需要策略搭配）
```

### 1.2 伤害公式

```
实际伤害 = 攻击 × 技能倍率 × (1 - 目标减伤率) × 暴击系数

减伤率 = 防御 ÷ (防御 + 1000 + 攻击方等级 × 50)
暴击系数 = 暴击时为 (1.5 + 暴击伤害加成)，否则为1
```

**示例**：
```
玩家攻击5000，技能倍率200%，Boss防御3000，玩家60级
减伤率 = 3000 ÷ (3000 + 1000 + 3000) = 42.8%
实际伤害 = 5000 × 2 × (1 - 0.428) = 5720

若暴击（暴击伤害+30%）：
实际伤害 = 5000 × 2 × 0.572 × 1.8 = 10296
```

> 最低伤害保底规则：`最终伤害 = max(攻击 × 1%, 计算伤害)`，防止减伤率趋近100%时伤害归零。

### 1.3 状态效果定义

| 状态效果 | 类型 | 效果描述 | 持续时间 | 叠加规则 |
|---------|------|---------|---------|----------|
| 灼烧 | DoT | 每秒造成目标最大生命值2%的伤害 | 5秒 | 不叠加，刷新持续时间 |
| 流血 | DoT | 每秒造成攻击方攻击力50%的伤害 | 5秒 | 最多叠加3层 |
| 减速 | 控制 | 移动/攻击速度降低50% | 5秒 | 不叠加，取最高值 |
| 冰冻 | 控制 | 无法移动和攻击 | 3秒 | 不叠加 |
| 麻痹 | 控制 | 无法移动和攻击 | 1秒 | 不叠加 |
| 眩晕 | 控制 | 无法移动和攻击 | 2秒 | 不叠加 |
| 击退 | 位移 | 将目标击退一段距离 | 即时 | — |
| 束缚 | 控制 | 无法移动，但可攻击 | 3秒 | 不叠加 |
| 破防 | 减益 | 防御力降低50% | 10秒 | 不叠加 |
| 无视防御 | 穿透 | 无视目标指定百分比防御力 | 即时（技能生效期间） | — |
| 恐惧 | 控制 | 无法移动和攻击，且随机移动 | 3秒 | 不叠加 |
| 沉默 | 控制 | 无法使用主动技能（可普攻/移动） | 3秒 | 不叠加 |

> **Boss免疫规则**：Boss对同一控制效果有5秒免疫期（被眩晕后5秒内不再被眩晕），但不同控制效果独立计算免疫。DoT效果（灼烧/流血）无免疫机制。

**解锁条件**：金丹期

**玩法**：
- 无限层挑战，每层怪物属性递增10%
- 每5层一个小Boss，每10层一个大Boss
- 通关层数越高，奖励越丰厚

**奖励表**：

| 层数 | 奖励 |

| 5层 | 灵石×3 + 强化石×5 |

## 四、野兽入侵防御系统

### 4.1 入侵机制

野兽入侵是玩家基地的周期性威胁事件。玩家需在各星球建立防御工事，抵御野兽潮的侵袭，保护已采集的资源和建筑。

**入侵规则**：

| 规则项 | 说明 |
|--------|------|
| 入侵间隔 | 每30分钟触发一次入侵波次 |
| 预警时间 | 入侵前5分钟发出预警（屏幕倒计时+警报音效） |
| 入侵波次 | 入侵怪物从基地边缘刷新，沿固定路径向核心建筑推进 |
| 基地血量 | 基地核心拥有独立生命值，被怪物攻击后扣除 |
| 战斗方式 | 自动防御（设施自动攻击）+ 玩家手动参与（可操控角色协防） |
| 离线保护 | 离线时防御设施自动运行，但效率降低20% |
| 解锁条件 | 筑基期开启入侵系统，起源星和玄铁星无入侵 |

**预警阶段**：
- 预警期间屏幕边缘出现红色脉冲，显示入侵类型和预计怪物数量
- 玩家可在此期间维修设施、调整防御阵型、补充弹药/能量
- 预警结束时，所有未完成的设施维修自动加速完成

---

### 4.2 入侵类型

每次入侵随机抽取类型，决定怪物的强度和数量。

| 入侵类型 | 概率 | 怪物数量 | 怪物属性倍率 | 特殊规则 |
|---------|------|---------|-------------|---------|
| 普通入侵 | 70% | 基础数量 | ×1.0 | 标准波次，无特殊机制 |
| 精英入侵 | 20% | 基础×1.5 | ×1.5 | 混入精英怪（自带特殊技能），精英怪有独立血条 |
| Boss入侵 | 10% | 基础×0.8 | ×2.0 | 混入一只Boss级怪物，Boss免疫控制，击杀后额外掉落 |

**怪物属性计算公式**：
```
入侵怪物等级 = 当前星球对应境界等级
入侵怪物生命 = 基础生命 × 类型倍率 × (1 + 已防御波次 × 0.02)
入侵怪物攻击 = 基础攻击 × 类型倍率 × (1 + 已防御波次 × 0.02)
```

> 每成功防御一波，后续入侵怪物属性永久提升2%，形成递增压力。
