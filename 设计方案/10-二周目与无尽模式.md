## 四、无尽模式（Endless Mode）

### 4.1 解锁条件

通关五周目，完成所有主线任务

### 4.2 基础规则

```
无尽模式：
  - 无限层数挑战
  - 每层怪物属性递增
  - 每10层一个Boss
  - 无法使用丹药（只能靠技能和装备）
  - 死亡后从最近的10层重新开始
```

### 4.3 怪物属性公式

**怪物属性**（分段函数）：
```
1-100层：基础属性 × (1 + 层数 × 0.1)
101-500层：基础属性 × (11 + (层数-100) × 0.15)
501-1000层：基础属性 × (71 + (层数-500) × 0.2)
1001+层：基础属性 × (171 + (层数-1000) × 0.3)
```

**Boss属性**：
```
Boss攻击 = 基础攻击 × (层数 ^ 1.2)
Boss防御 = 基础防御 × (层数 ^ 1.1)
Boss生命 = 基础生命 × (层数 ^ 1.5)
```

> **等级规则**：无尽模式中，Boss/怪物等级 = 当前层数。例如第100层Boss等级为100，第500层Boss等级为500。伤害公式中的"攻击方等级"取当前层数值。

> **Boss基础属性定义**（固定值，不随玩家实际属性变化）：
> - 基础攻击 = 渡劫10阶攻击 = 500,000
> - 基础防御 = 渡劫10阶防御 = 250,000
> - 基础生命 = 渡劫10阶生命 = 2,000,000

### 4.4 层数奖励

**每层奖励**：
```
无尽积分 = 1
星币 = 层数 × 10000
强化石 = 层数 × 2
```

**每10层Boss奖励**：
```
无尽积分 = 层数
灵石 = 层数 / 10
突破石 = 1-5个
进化石 = 1-3个
词条石 = 1-2个
```

## 五、无限成长系统

### 5.1 成长维度总览

| 成长维度 | 上限 | 成长方式 | 每次收益 |
|---------|------|---------|---------|
| 装备强化 | 一周目+15 / 二~五周目+30 / 无尽模式无硬上限（+50以上衰减） | 消耗强化石 | 强化系数 = 1.25^等级（+50以上线性衰减） |
| 装备品质 | 无上限 | 消耗品质材料 | 10级前每级+0.5，10级后每级+0.3（分段公式） |
| 装备词条 | 无上限 | 消耗词条石 | 随机属性提升 |
| 境界突破 | 无上限 | 消耗星元+材料 | 基础属性提升 |
| 功法进化 | 无上限 | 消耗进化材料 | 技能倍率提升 |
| 无尽天赋 | 有上限（各节点最大等级，满级需3060点） | 消耗无尽积分 | 永久属性加成 |

### 5.2 装备无限强化

**强化等级上限**（详见04-装备系统.md及补充-数值公式统一.md）：
- 一周目：+15（硬上限）
- 二周目~五周目：+30（硬上限）
- 无尽模式：无硬上限，但+50以上采用衰减公式

**强化系数公式**：
```
+50以内：强化系数 = 1.25 ^ 强化等级
+50以上：强化系数 = 1.25^50 × (1 + (强化等级-50) × 0.05)
  即+50之后每级增加固定5%而非乘以1.25
```

| 强化等级 | 系数 | 累计提升 |
|---------|------|---------|
| +0 | 1.00 | 0% |
| +15 | 28.42 | 2742% |
| +30 | 807.79 | — |
| +50 | 70,065 | +7,006,400% |
| +60 | 105,097 | — |
| +100 | 245,227 | — |
| +500 | 1.4×10⁴⁸ | 极大 |
| +1000 | 2.0×10⁹⁶ | 极大 |

> 注：+50以上指数增长转为线性增长（每级+5%），防止数值溢出。无尽模式强化系数随等级呈指数→线性增长，是核心成长驱动力。

### 5.3 装备品质无限

**品质系数公式（分段递增）**：
```
品质系数 = 1 + 0.5 × min(品质等级, 10) + 0.3 × max(0, 品质等级 - 10)

前10级每级+0.5（增长率较高，快速建立基础）
10级之后每级+0.3（增长率递减，防止数值失控）
```

> **与标准品质体系的关系**：标准品质体系（白1.0→绿1.3→蓝1.7→紫2.2→橙3.0→红4.0→太古5.0）到太古品质(5.0)即为终点。无限品质是无尽模式专属的独立品质系统，从等级1开始（系数1.5），不与标准品质体系直接衔接。进入无尽模式后，装备品质切换为无限品质体系，原标准品质装备保留但不再提升品质等级。

| 品质等级 | 系数 | 每级增量 | 累计提升 |
|---------|------|---------|---------|
| 1（无限·白） | 1.5 | +0.5 | +50% |
| 5（无限·蓝） | 3.5 | +0.5 | +250% |
| 10（无限·钻石） | 6.0 | +0.5 | +500% |
| 20 | 9.0 | +0.3 | +800% |
| 50 | 18.0 | +0.3 | +1700% |
| 100 | 33.0 | +0.3 | +3200% |

### 5.5 功法无限进化

**进化公式**：
```
进化后倍率 = 原倍率 × (1 + 进化等级 × 0.2)
进化后冷却 = 原冷却 × (1 - 进化等级 × 0.01)（最低50%）
```

|---------|---------------|------|
| 0 | 350% | 10秒 |
| 10 | 1050% | 9秒 |
