## 三、伤害公式

```
实际伤害 = 攻击 × 技能倍率 × (1 - 目标减伤率) × 暴击系数

减伤率 = 防御 ÷ (防御 + 1000 + 攻击方等级 × 50)
暴击系数 = 暴击时为 (1.5 + 暴击伤害加成)，否则为1
```

> 最低伤害保底规则：`最终伤害 = max(攻击 × 1%, 计算伤害)`，防止减伤率趋近100%时伤害归零。

**对Boss战斗的影响**（以化神10阶为例）：

```
无成就属性：攻击1,860,950，防御1,490,000，生命6,200,000
全成就属性：攻击 ×(1+1.10+0.25) = ×2.35 → 4,373,233
            防御 ×(1+1.10) = ×2.10 → 3,129,000
            生命 ×(1+1.10) = ×2.10 → 13,020,000
```

## 七、装备随机性系统

### 7.1 词条规则

- 每件装备有5个词条槽
- 槽1-3：主词条（正面效果）
- 槽4：副词条（随机正面或负面，60%/40%概率）
- 槽5：特殊词条（强力但有代价）

### 7.2 软/硬上限（与01文档一致）

| 属性 | 软上限 | 硬上限 | 说明 |
|------|--------|--------|------|
| 暴击率 | 30% | 80% | 超过30%部分效果减半，硬上限80% |
| 暴击伤害 | 100% | 300% | 超过100%部分效果减半，硬上限300% |
| 穿透 | 30% | 75% | 超过30%部分效果减半，硬上限75% |
| 闪避率 | 25% | 50% | 超过25%部分效果减半，硬上限50% |
| 攻击/防御/生命加成 | 50% | 200% | 超过50%部分效果减半，硬上限200% |

> 软上限：超出部分效果减半。硬上限：任何手段不可超越的绝对上限。与01文档第四节「全局属性约束」一致。

### 7.3 防无敌机制

| 机制 | 作用 |
|------|------|
| 词条互斥 | 限制词条组合 |
| 软/硬上限 | 限制属性堆叠（逐属性定义，见7.2） |
| 负面词条 | 强力词条有代价 |
| 数值随机 | 难以达到理论最大值 |

```
星元需求：分段递增，见属性表（无限境界：3000000000×1.10^(等级-61)）
```

### 装备属性
```
装备基础属性 = 品质系数 × 部位系数 × 境界基数
强化后属性 = 基础属性 × 强化系数
强化系数 = 1.25 ^ 强化等级（+50以上采用衰减公式，见补充文档2.3节）
```

### 伤害计算
```
实际伤害 = 攻击 × 技能倍率 × (1 - 减伤率) × 暴击系数
减伤率 = 防御 ÷ (防御 + 1000 + 攻击方等级 × 50)
暴击系数 = 暴击时为 (1.5 + 暴击伤害加成)，否则为1
```

### 生产效率
```
单次生产时间 = 基础时间 ÷ (1 + 设备等级×设备加速系数) ÷ (1 + 空间折叠器等级×0.1) ÷ 批量生产蓝图倍率 ÷ 星际传送门倍率

设备加速系数：熔炼炉/蒸馏器 = 0.2，萃取机/精炼台 = 0.15，炼丹炉/锻造台不适用
批量生产蓝图倍率 = 2.0（元婴期科技树解锁，同时间产出翻倍）
星际传送门倍率 = 2.0（元婴期科技树解锁）
```

### 无尽模式怪物属性
```
1-100层：基础 × (1 + 层数 × 0.1)
101-500层：基础 × (11 + (层数-100) × 0.15)
501-1000层：基础 × (71 + (层数-500) × 0.2)
1001+层：基础 × (171 + (层数-1000) × 0.3)

Boss攻击 = 基础攻击 × (层数 ^ 1.2)
Boss防御 = 基础防御 × (层数 ^ 1.1)
Boss生命 = 基础生命 × (层数 ^ 1.5)
```

**Boss基础属性定义**（固定值，不随玩家实际属性变化）：
- 基础攻击 = 渡劫10阶攻击 = 500,000
- 基础防御 = 渡劫10阶防御 = 250,000
- 基础生命 = 渡劫10阶生命 = 2,000,000

> 注：Boss基础属性固定为渡劫10阶玩家基础属性，不随玩家实际属性变化。普通怪物基础属性同样使用渡劫10阶基础值，通过分段倍率公式递增。详见《10-二周目与无尽模式.md》4.3节。
