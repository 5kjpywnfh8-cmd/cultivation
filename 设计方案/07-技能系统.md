> **打断机制**：部分Boss在释放大招时会进入"蓄力"状态（头顶出现红色进度条），此时使用带有眩晕、麻痹、击退效果的技能可以打断Boss施法。可打断技能：雷引术（麻痹）、雷霆万钧（眩晕）、玄冰掌（击退）。金刚护体和天地归虚等无敌技能虽无法打断Boss，但可在Boss大招期间保命。打断成功可使Boss进入3秒虚弱状态（防御-50%）。

> **雷属性标签**：雷引术、雷霆万钧标记为"雷属性"，受装备词条"雷属性伤害+X%"加成（如天晶套装6件效果"雷属性伤害+30%"）。Boss的万雷齐发等技能也属于雷属性，但Boss技能不受玩家装备加成影响。

## 五、技能搭配推荐

### 练气-筑基期
```
主动：星火术 + 疾风步
被动：聚灵术
思路：星火术输出，疾风步保命
```

### 金丹期
```
主动：御剑术 + 玄冰诀 + 玄冰掌（打断）/ 疾风步
被动：天罡护体
思路：御剑术主输出，玄冰诀减速，玄冰掌可打断Boss蓄力大招，疾风步闪避保命
```

### 元婴期
```
主动：雷霆万钧 + 御剑术 + 雷引术 + 疾风步
被动：天罡护体 + 混元功
思路：雷霆万钧爆发+眩晕，雷引术麻痹控制
```

### 化神期
```
主动：破空斩 + 混沌掌 + 雷霆万钧 + 疾风步
被动：不灭金身 + 混沌大道
思路：破空斩高爆发，不灭金身保命容错
```

### 渡劫期
```
主动：诛仙剑阵 + 万法归宗 + 破空斩 + 净化之光（解控）+ 天地归虚（无敌）
被动：天道轮回 + 混沌大道 + 不灭金身
思路：诛仙剑阵起手，万法归宗复制，净化之光解除控制，天地归虚应对致命伤害，三重保命
```

## 六、功法进化系统（二周目解锁）

### 进化公式
```
进化后倍率 = 原倍率 × (1 + 进化等级 × 0.2)
进化后冷却 = 原冷却 × (1 - 进化等级 × 0.01)（最低50%）
```

```
进化消耗 = 进化等级 × 5 进化精华 + 进化等级 × 100万 星币
```

### 进化成功率
```
成功率 = max(10%, 100% - 进化等级 × 2%)
```

## 七、技能公式汇总

### 7.1 技能伤害公式

```
实际伤害 = 攻击 × 技能倍率 × (1 - 减伤率) × 暴击系数

减伤率 = 防御 ÷ (防御 + 1000 + 攻击方等级 × 50)
暴击系数 = 暴击时为 (1.5 + 暴击伤害加成)，否则为1

最低伤害保底：最终伤害 = max(攻击 × 1%, 计算伤害)
```

### 7.2 技能冷却公式

```
最终冷却 = 基础冷却 × (1 - 冷却缩减总额)

冷却缩减来源：
  混沌大道（被动）：-20%
  万法归宗成就三阶段：-10% / -20% / -30%
  装备词条（技能冷却-X%）：最多-2%×5件=-10%
  天晶套装6件效果：-10%

冷却缩减上限：最高50%，超出部分无效（防止后期内容过于简单）
实际冷却下限：不低于1秒
```

### 7.3 功法进化公式

```
进化后倍率 = 原倍率 × (1 + 进化等级 × 0.2)
进化后冷却 = 原冷却 × (1 - 进化等级 × 0.01)（最低为原冷却的50%）
进化消耗 = 进化等级 × 5 进化精华 + 进化等级 × 100万 星币
成功率 = max(10%, 100% - 进化等级 × 2%)
```
